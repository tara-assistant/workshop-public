        Plan with your agent

        Use the portable skill to prepare a trip file, then import it here. The skill works independently of this app.

        My Trip Planner skill

        Use the portable My Trip Planner skill and its install README to research a schema-v1 JSON trip. It does not connect to or control this app.

        Dates matter

        Provide real, confirmed start and end dates and a date for every day. The agent must ask and wait for missing dates. Only an explicitly requested illustrative demo may use disclosed example dates; its title and note must clearly label it as illustrative, not a real travel plan.

        Import a plan

        1. Install the skill or give SKILL.md to your agent, then request your trip.
        2. Save the returned trip as a .json file.
        3. Open Menu → My trips → Import JSON or GPX and choose the JSON file.
        4. Export JSON from Menu → Share and export to keep a full backup.

        Services and credits

        Public services power the map, place search, directions, weather and trip photos.

        Map and route services

        • Map: MapLibre GL, OpenFreeMap and © OpenStreetMap contributors. Required map attribution remains visible beside the map.
        • Satellite: EOX Sentinel-2 cloudless, containing modified Copernicus Sentinel data.
        • Terrain: AWS Terrain Tiles.
        • Place search: Nominatim.
        • Road directions: OSRM by FOSSGIS.

        Forecasts and photos

        • Weather and elevation: Open-Meteo, CC BY 4.0; free API use is non-commercial.
        • Place photos: Wikipedia and Wikimedia Commons. Each itinerary photo links to its file page and licence.
        Advanced provider URLs

        Provider URLs use public services by default. Enter complete HTTPS endpoints, or HTTP for localhost or 127.0.0.1, without credentials, query or fragment.
